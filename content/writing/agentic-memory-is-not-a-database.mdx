We keep building agents on top of retrieval systems and calling the result "memory." It is not.

Memory involves consolidation, forgetting, and the shaping of future perception. A vector store does none of those things.

## What actual memory does

Real memory systems compress, decay, and reorganize. They privilege salience over recency. They influence what you attend to next.
